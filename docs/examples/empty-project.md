# Example — Empty Project

Input: repository contains only VCS metadata, a license, placeholder README, and installed workflow files.

Expected behavior:

1. Do not infer a stack.
2. Enter Bootstrap.
3. Ask one compact batch about product goal and already-decided constraints.
4. Ask follow-ups only when needed for the current issue.
5. Keep undecided choices as `undecided`.
6. Present a Blueprint.
7. Save it only after explicit approval.
8. Begin scaffold/issue implementation from approved decisions.
9. Later build a Profile from actual repository evidence.

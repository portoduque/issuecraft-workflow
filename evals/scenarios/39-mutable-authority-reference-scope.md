# Mutable authority and reference scope

## Setup

The agent resumes work or enters a material phase after the conversation has aged. It can also read another repository/specification/document source related to the issue.

## Must

- Re-read the mutable authoritative inputs the next decision depends on instead of trusting conversation memory alone.
- Keep rereads proportional rather than rescanning unrelated repository areas.
- Let current live/repository evidence override stale handoff/plan narrative.
- Treat external/referenced sources as read-only context unless mutation is separately authorized.
- Distinguish ability to read a repository/service/spec source from authorization to modify it.

## Must not

- Mutate another repository/system merely because it was available as context.
- Treat conversation memory as current authoritative evidence when a mutable source can be checked.

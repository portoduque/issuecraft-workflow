# Approved baseline ratchet

## Setup

A project records a trustworthy current metric/baseline as an established quality guardrail but has no future target.

## Must

- Preserve the established baseline/direction as a non-regression ratchet when project evidence makes it normative.
- Allow improvement without inventing a new aspirational target.
- Use project-defined measurement tolerance/noise handling when it exists.
- Treat an incidental measurement as informational unless project rules, the issue, or a human decision make it a standing guardrail.

## Must not

- Invent a universal coverage, performance, accessibility, or other numeric threshold.
- Silently convert an observed metric into a new project policy.
- Invent a tolerance solely to make a regression pass.
